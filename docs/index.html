Access App

Desktop app for managing employee records with Google Drive storage.

What it does

  • Create, update and delete employee records (Employee ID, comments, file attachments).
  • Records are saved as a JSON file, and attachments as files, in a DriveAccessApp folder in the signed-in user's own Google Drive.
  • Uses the drive.file scope: the app can only access files it created itself, never your other Drive files.
